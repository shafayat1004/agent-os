# AGENTS

## Commands
- test: python3 -m unittest discover -s tests
- validate: ./bin/agentos all
- docs lint: python3 .claude/skills/ste-writing/scripts/ste-lint.py <file>

## Invariants
- The validator and bin/ import the Python standard library only. No third-party packages.
- All tests pass before any done claim.
- A subset parser (yaml_min, jsonschema_min) raises on input it does not support. It never silently accepts or corrupts.
- SPEC.md and ROADMAP.md contain no em-dash. The test suite hard-fails on one.

## Forbidden
- Do not add a third-party dependency anywhere under agentos/ or bin/.
- Do not weaken a check, a schema, or a test to make a failing repo pass.
- Do not commit secrets, .save files, or __pycache__ output.

## Approval gates
- Changes to SPEC.md, ROADMAP.md, WHITEPAPER.md, and schemas/ need human sign-off.
- Version bumps and release tags need human sign-off.

## Scope
- may edit: agentos/, tests/, bin/, templates/, hooks/, examples/, policies/, evidence/, skills/, docs/, README.md, .gitignore, .claude/, .opencode/, .github/
- ask first: SPEC.md, ROADMAP.md, WHITEPAPER.md, schemas/
- never: .git, _autogenerated_, *.render

## Conventions (pointer)
- Docs follow the ste-writing skill (.claude/skills/ste-writing). Code follows the descriptive-names standard set in v0.2.

## Operating procedure
- At task start, set STATE.yaml task_id, goal, and next_action. Keep STATE.yaml current as you work.
- Append one line to evidence/ledger.ndjson for each verified claim: the claim, the proof, the timestamp.
- Before any done claim, run ./bin/agentos all. Every check must pass.
- To claim done, set stop_readiness: ready in STATE.yaml. The stop hook then grades verification_status and runs the test suite.
