# AGENTS (EggShell, derived)

## Commands
- Frontend lib build: ./eggshell build-lib
- Backend lib build: dotnet build -c "Web Debug"
- Format F#: dotnet tool run eggshell-fmt -- <file.fs>
- Done gate: scripts/verify-done.sh <build-log>

## Invariants
- Build is green before any done claim. No stale-cache false greens.
- Frontend is Fable 5, .NET 10 SDK, React 19.2 + react-native-web 0.21.
- Accessibility ships by default on every UI change.

## Forbidden
- Never run dotnet fable directly. It emits stray .fs.js.
- No new render DSL. Convert stragglers to pure F#.
- No banned NuGet packages (Moq, AutoMapper). No em-dash in prose.

## Approval gates
- Do not modify App* or Suite* without explicit request.
- Do not start goals F, G, or H yet.

## Scope
- may edit: Lib*, LibUi*, LibRouter, LibAutoUi, LibLifeCycleUi, ThirdParty, Meta
- ask first: App*, Suite*
- never: _autogenerated_, *.render, *.typext.fs, *.fs.js

## Conventions (pointer)
- Full conventions: AppEggShellGallery/public-dev/docs/ (fsharp/, runbooks/, accessibility/).
